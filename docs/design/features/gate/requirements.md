# Requirements: gate

Status: live

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the test or the gate plant that fails when it is violated. A behaviour with no test is not a row here: it is listed as a gap in the delegation report and gets its row when its test exists.

| SHG-001 | THE gate SHALL pass the clean fixture product in the full matrix (five sizes, both themes, both languages) and write one capture index that shows every capture, the wide-font pass's included. | `test/gate-selftest.mjs::the clean fixture passes every check in the full matrix (five sizes, both themes, both languages)` |
| SHG-002 | THE gate CLI SHALL exit 2 without a subject (naming that `--expect-brand` is required) and 1 on a failing subject, printing the failure. | `test/gate-selftest.mjs::the CLI exits 2 without a subject and 1 on a failing subject` |
