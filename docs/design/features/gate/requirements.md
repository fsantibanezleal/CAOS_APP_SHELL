# Requirements: gate

Status: live

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the test or the gate plant that fails when it is violated. A behaviour with no test is not a row here: it is listed as a gap in the delegation report and gets its row when its test exists.

| ID | Requirement | Gate |
|---|---|---|
| SHG-001 | THE gate SHALL pass the clean fixture product in the full matrix (five sizes, both themes, both languages) and write one capture index that shows every capture, the wide-font pass's included. | `test/gate-selftest.mjs::the clean fixture passes every check in the full matrix (five sizes, both themes, both languages)` |
| SHG-002 | THE gate CLI SHALL exit 2 without a subject (naming that `--expect-brand` is required) and 1 on a failing subject, printing the failure. | `test/gate-selftest.mjs::the CLI exits 2 without a subject and 1 on a failing subject` |
| SHG-003 | THE local server of the gate SHALL answer as GitHub Pages does: a directory without a slash redirects with 301, a missing file answers 404 with no SPA fallback, JSON answers as JSON, and a path outside the root answers 404. | `test/gate.test.ts::the local server answers as GitHub Pages does (G4 runs against what will be deployed)` |
| SHG-004 | THE gate's G6 pixel arithmetic SHALL find a painted rectangle exactly, treat a uniform region as blank and not double count unions. | `test/gate.test.ts::G6 arithmetic: a drawn rectangle is found exactly, a uniform region is blank, unions do not double count` |
| SHG-005 | WHEN the brand of the page is not `--expect-brand`, THE gate SHALL fail under G1 and measure nothing else. | `test/gate-selftest.mjs::brand` |
| SHG-006 | WHEN the page logs a console error, raises a page error, or a GET answers 400 or above, THE gate SHALL fail under G3, including an error that appears only in one case. | `test/gate-selftest.mjs::console`, `test/gate-selftest.mjs::http404`, `test/gate-selftest.mjs::case-only` |
