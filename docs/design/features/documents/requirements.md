# Requirements: documents

Status: live

EARS (Mavin et al., RE'09, doi:10.1109/RE.2009.9). Every requirement names the test or the gate plant that fails when it is violated. A behaviour with no test is not a row here: it is listed as a gap in the delegation report and gets its row when its test exists.

| ID | Requirement | Gate |
|---|---|---|
| SHD-001 | THE DocPage SHALL render as a prose page (`page-body prose caos-doc`) and each DocSection SHALL declare its citations as `data-refs` or, when it cites none, a stated `noRefsReason` as `data-no-refs-reason`, without rendering a references row of its own. | `test/workbench.test.tsx::DocSection declares its references (listed once at the end of the page) and a section without them must say why (ADR-0017 §4)` |
| SHD-002 | WHEN the sections of a DocPage cite works, THE DocPage SHALL end in exactly one references block that lists each full citation once, in the order of first appearance across its sections. | `test/docReferences.test.ts::a DocPage of three sections ends in one block, each citation once, in the order of first appearance` |
| SHD-003 | THE `firstAppearance` function SHALL list each citation id once, in the order the sections give them, and an empty input SHALL give an empty list. | `test/docReferences.test.ts::firstAppearance lists each id once, in the order the sections give them` |
| SHD-004 | WHEN the sections sit inside a Tabs panel, THE open panel SHALL end in a references block that lists only the citations of that panel. | `test/docReferences.test.ts::inside Tabs the block of the open panel lists only that panel, at its end` |
| SHD-005 | WHERE scopes nest (a sub-tab panel inside a tab panel inside a page), THE innermost scope SHALL list its own sections' citations and each outer scope SHALL list only its own. | `test/docReferences.test.ts::the innermost scope wins: sub-tab panel, tab panel and page each list their own sections` |
| SHD-006 | WHEN every section of a scope declares a reason and no citations, THE scope SHALL render no references block. | `test/docReferences.test.ts::a section with a reason and no refs adds nothing, and no block renders` |
| SHD-007 | WHEN the interface language changes, THE references block SHALL keep its order and translate its heading. | `test/docReferences.test.ts::switching the language keeps the order and translates the heading` |
| SHD-008 | THE references block SHALL be the last element of the page body, and no section SHALL end in a references row of its own. | `e2e/doc-layout.test.ts::a wide document page: text fills its section, the references block is the last element of the body` |
| SHD-009 | THE paragraphs of a wide document page SHALL take the full width of their section, a list item SHALL differ from it only by the list indent, and a caption SHALL keep its measure and not fill the column. | `e2e/doc-layout.test.ts::a wide document page: text fills its section, the references block is the last element of the body` |
| SHD-010 | THE stylesheet SHALL NOT cap the width of paragraphs, list items, blockquotes, definitions or callouts of a prose page, and SHALL cap equation and figure captions at `--measure-text`. | `test/base08.test.tsx::BL-008 (0.11.0): text blocks in a document take the full column; only captions keep a measure` |
| SHD-011 | THE prose page SHALL keep the reading measure and SHALL stay centred, and no other rule that targets `.page-body` SHALL redefine the measure or remove the centring. | `test/layout-primitives.test.ts::a prose page keeps the reading measure`, `test/layout-primitives.test.ts::no other rule targeting .page-body redefines the measure`, `test/layout-primitives.test.ts::a prose page stays centered`, `test/layout-primitives.test.ts::no other rule targeting .page-body removes the centering` |
| SHD-012 | THE wide workbench opt-in SHALL still override the prose measure, and the narrow-column primitive (`.measure`) SHALL be a per-block width, not a page width. | `test/layout-primitives.test.ts::the wide workbench opt-in still overrides the measure`, `test/layout-primitives.test.ts::the narrow-column primitive is per-block, not a page width` |
| SHD-013 | THE stylesheet SHALL define both the reading width (`--maxw`) and the workbench width (`--maxw-wide`). | `test/layout-primitives.test.ts::the reading and instrument budgets are both defined` |
| SHD-014 | THE layout test's rule parser SHALL see compound and descendant rules, so that the layout checks cannot pass by missing a rule. | `test/layout-primitives.test.ts::the parser sees compound and descendant rules (self-check)` |
| SHD-015 | IF an Equation has no caption, THEN THE Equation SHALL report it, and an Equation with a caption SHALL report nothing. | `test/adrRuntimeChecks.test.tsx::an equation without a caption is reported (ADR-0017 s2)` |
| SHD-016 | IF a citation has no DOI or URL, a citation id is duplicated, or a Cite names an unknown id, THEN THE citation components SHALL report each problem by name. | `test/adrRuntimeChecks.test.tsx::a citation without a doi or url, a duplicate id and an unknown Cite are reported (ADR-0017 s4)` |
| SHD-017 | WHEN a ReferenceList is rendered, THE shell SHALL report that it is superseded by the end-of-page references block. | `test/adrRuntimeChecks.test.tsx::a bibliography outside the end-of-page block is reported as superseded (ADR-0017 s4)` |
| SHD-018 | WHEN a section declares references while its page or open tab shows no references block, THE gate SHALL fail with the citations the page never lists. | `test/gate-selftest.mjs::refs-missing` |
| SHD-019 | WHEN content follows the references block, THE gate SHALL fail with the message that the references must be the last block of the page or tab. | `test/gate-selftest.mjs::refs-mid` |
| SHD-020 | WHEN a document route holds less text than the floor, THE gate SHALL fail it as a thin document. | `test/gate-selftest.mjs::thin-doc` |
